# dotfiles

mainly nvim + zsh

## stuff
- `nvim/`: nvim config with lazy.nvim
- `.zshrc` / `daniel.zsh-theme`: zsh config with oh-my-zsh
- `.vimrc`: old vim config for reference
- `.gitconfig`: git aliases + defaults
- `setup.sh`: rudimentary script to install zsh + omz and symlink files

## setup
```
git clone https://github.com/danielwzyang/dotfiles ~/dotfiles
cd ~/dotfiles
chmod +x setup.sh
./setup.sh
```
